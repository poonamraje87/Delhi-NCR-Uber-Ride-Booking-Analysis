# 🚕 NCR Ride Booking Analysis Using SQL

## 📌 Project Overview

This project analyses ride-booking data using **MySQL** to understand
booking patterns, completed rides, revenue, vehicle performance, ride
distance, cancellations, ratings and payment methods.

The project was created as a practical SQL data analysis project using
an NCR/Uber-style ride-booking dataset.

## 🎯 Project Objectives

-   Analyse overall ride-booking activity.
-   Identify successfully completed rides.
-   Calculate completion rate and revenue from completed rides.
-   Compare completed bookings and revenue across vehicle types.
-   Analyse total and average ride distance.
-   Identify common customer and driver cancellation reasons.
-   Analyse driver and customer ratings.
-   Understand frequently used payment methods.
-   Identify pickup locations with higher-than-average ride counts.
-   Find rides with booking values above the overall average.
-   Practise SQL aggregation, filtering, conditional logic and
    subqueries.

## 🧠 Example: Subquery Analysis

One of the questions identifies rides whose booking value is higher than
the overall average.

The inner query calculates the average booking value, and the outer
query finds rides above that average.

``` sql
SELECT 
    COUNT(*) AS rides_above_average,
    ROUND(
        COUNT(*) * 100.0 / (SELECT COUNT(*) FROM ncr_ride_bookings),
        2
    ) AS percentage_of_total
FROM ncr_ride_bookings
WHERE `Booking Value` > (
    SELECT AVG(`Booking Value`)
    FROM ncr_ride_bookings
);
```

This demonstrates how a **subquery** can be used to compare individual
records against an overall calculated value.

## 📈 Key Analysis Findings

-   The analysis identified **38,439 completed rides** in the SQL
    dataset.
-   Completed rides covered approximately **24.18 lakh km** in total.
-   The average distance of a completed ride was approximately **26
    km**.
-   Vehicle-wise analysis was used to compare completed bookings and
    revenue.
-   Cancellation analysis helps identify the main reasons for rides
    being lost.
-   Location-level analysis highlights pickup areas with higher booking
    activity.

    rides.

## 💡 Business Insights

-   **Booking performance:** Comparing total and completed bookings
    helps understand the overall success of ride requests.
-   **Vehicle performance:** Vehicle-wise booking and revenue analysis
    shows which vehicle categories contribute more to completed rides.
-   **Ride distance:** Total and average distance provide a view of the
    travel volume handled by completed rides.
-   **Cancellations:** Customer and driver cancellation reasons can help
    identify areas where the booking experience could be improved.
-   **Pickup demand:** Locations with above-average ride counts can
    indicate areas with relatively higher booking activity.
-   **Booking value:** Rides above the average booking value can be used
    to understand higher-value transactions.
-   **Ratings:** Driver and customer ratings provide additional
    information about the ride experience.
